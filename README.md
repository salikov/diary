# Как установить аналитику оценок

## Установка вручную

1. Установите официальное расширение [Tampermonkey](https://www.tampermonkey.net/) для Chrome.
2. Нажмите значок Tampermonkey в Chrome и откройте **Панель управления / Dashboard**.
3. Нажмите **«Добавить новый скрипт»** (значок `+`), удалите шаблон и вставьте целиком содержимое файла [`diary-analytics.user.js`](https://raw.githubusercontent.com/salikov/diary/refs/heads/main/diary-analytics.user.js).
4. Сохраните скрипт сочетанием `Ctrl+S`. Проверьте, что он включён в списке скриптов Tampermonkey.
5. Откройте [электронный дневник](https://diary.e-schools.by), войдите в него как обычно и обновите страницу.
6. В правом нижнем углу страницы появится синяя кнопка **«Аналитика оценок»**. Нажмите её, чтобы открыть панель. Выберите ученика и четверть.

Если скрипт устанавливается по ссылке с GitHub, вместо шагов 2–4 нажмите **«Установить скрипт»** на странице проекта и подтвердите установку в Tampermonkey.

## Если кнопка не появилась

- Проверьте, что адрес страницы начинается именно с `https://diary.e-schools.by/`.
- В панели Tampermonkey убедитесь, что переключатель рядом со скриптом включён.
- Откройте настройки Chrome для Tampermonkey и разрешите доступ к сайту `diary.e-schools.by`.
- Обновите страницу дневника после включения скрипта.
- Нажмите значок Tampermonkey на странице дневника и проверьте, что скрипт указан среди запущенных.

Скрипт использует активную сессию дневника только в браузере. Вводить логин и пароль в скрипт не нужно.
